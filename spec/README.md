Each version directory holds the specification text, the normative JSON Schemas and the worked examples.

A breaking change gets a new version directory and a new URI, as A2A requires of extensions. Agents and memories negotiate by URI, so different versions can run side by side.

The URI `https://w3id.org/mem2a/v0.1` is reserved for this draft. We will register the redirect with [w3id.org](https://w3id.org/) when the repository is public.
