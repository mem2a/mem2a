# Take part

Mem2A is a draft, and now is the cheapest time to change it. You don't need to write code to make a difference.

## Ways to help

| You can | How |
| --- | --- |
| Tell us about an agent that did something it shouldn't have | [Share a use case](https://github.com/mem2a/mem2a/issues/new?template=use-case.yml): three plain questions |
| Weigh in on a design question | Comment on an [open question](https://github.com/mem2a/mem2a/issues?q=is%3Aissue+is%3Aopen+label%3A%22open+question%22) |
| Try Mem2A on real agents | [Become a design partner](https://github.com/mem2a/mem2a/issues/new?template=design-partner.yml) |
| Point out a failure mode we missed | [Report a failure mode](https://github.com/mem2a/mem2a/issues/new?template=failure-mode.yml) |
| Change the spec | Open a [spec change](https://github.com/mem2a/mem2a/issues/new?template=spec-change.yml), then a pull request |
| Build an implementation, in any language | Follow the [implementer's guide](../implementers-guide.md), then [get listed](../../IMPLEMENTATIONS.md) |
| Report two implementations that don't work together | File an [interop report](https://github.com/mem2a/mem2a/issues/new?template=interop-report.yml) |
| Help maintain the project | Say so on [issue #19](https://github.com/mem2a/mem2a/issues/19) |

New to the code? Start with a [good first issue](https://github.com/mem2a/mem2a/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) and the [contributor guide](../../CONTRIBUTING.md).

## Where to talk

- **In public:** [GitHub Discussions](https://github.com/mem2a/mem2a/discussions) for questions and ideas, and [issues](https://github.com/mem2a/mem2a/issues) for bugs, spec changes and open questions.
- **In private:** [Sentra's contact page](https://www.sentra.app/contact), for design partnerships, deployments, or anything you'd rather not post. The [maintainers](../../MAINTAINERS.md) work at Sentra.
- **Security problems:** never in public. Follow the [security policy](../../SECURITY.md).

## How decisions get made

Normative changes start as an issue, land as a pull request, and stay open for comment for at least seven days. A change is accepted by lazy consensus, and every decision is recorded with its reasons ([governance](../../GOVERNANCE.md)). The plan is to propose Mem2A to the A2A project as an official extension, and to hand it to a neutral home with maintainers from several companies ([roadmap](../roadmap.md)).

Everyone taking part follows the [code of conduct](../../CODE_OF_CONDUCT.md).
